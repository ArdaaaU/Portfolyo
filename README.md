## ✨ Özellikler

- 🌟 **Dark Glassmorphism & Ambient Glow**: Arka planda yumuşak ışık gradyanları, `backdrop-filter: blur(20px)` ve modern kart tasarımları.
- 💻 **İnteraktif Bash Terminali**: macOS pencere kontrolleri ile geliştirici profilini ve durumunu interaktif sergileyen terminal simülatörü.
- ⚡ **Kategori Bazlı Filtrelenebilir Proje Vitrini**:
  - `Turnuva Ağacı` (Supabase Realtime, PostgreSQL) — [turnuvaagac.vercel.app](https://turnuvaagac.vercel.app)
  - `ASCII Knight` (HTML5 Canvas 2D, Web Audio API, Uint32Array 60 FPS) — [ascii-knight.vercel.app](https://ascii-knight.vercel.app)
  - `KYK Yemek Portalı` (Mobil öncelikli lightweight dashboard) — [kykyemek.vercel.app](https://kykyemek.vercel.app)
  - `Cyber Shield` (WCAG uyumlu pedagojik eğitim platformu) — [siberzorbalik.vercel.app](https://siberzorbalik.vercel.app)
  - `CoreMax` (Donanım & oyuncu ekipmanları e-ticaret vitrini) — [coremaxtech.vercel.app](https://coremaxtech.vercel.app)
  - `Ders Programı & Sınav Takvimi` (Vanilla JS, LocalStorage, Dark/Light Mod) — [dersprog.vercel.app](https://dersprog.vercel.app)
  - `Jet Engine 3D` (Three.js / WebGL parça simülasyonu)
  - `Öğrenci Bilgi Sistemi (OBS)` (Flask, SQLite, 3 rollü yetkilendirme)
- 📋 **Tek Tıkla E-Posta Kopyalama**: Geri bildirimli kopyalama mekanizması.
- 📱 **Tam Duyarlı (Responsive)**: Masaüstü, tablet ve mobil cihazlar için optimize edilmiş layout.
- 🔒 **Gizlilik Korumalı**: Kişisel telefon ve açık adres bilgileri korunarak profesyonel iletişim kanalları ön plana çıkarılmıştır.

## 🛠️ Teknolojiler & Araçlar

- **Front-End**: Semantik HTML5, CSS3 (Modern Flexbox & CSS Grid, Custom Properties), Modern JavaScript (ES6+)
- **İkonlar & Tipografi**: FontAwesome 6, Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)
- **Dağıtım (Deploy)**: Vercel
